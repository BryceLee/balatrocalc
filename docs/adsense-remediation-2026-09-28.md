日期：2026-09-28。状态：本地整改已实施，尚未部署；AdSense 后台、广告真实投放和地区同意状态未核验。下面的 ADS-* 是预检工具的编号，不是 Google 官方政策编号。本文是操作清单，不是通过审核的承诺。

## 先校正报告

- 预检表仅列 1 个 Medium Fail，AI 点评另列 High 风险；不能把 AI 推测当成已证实的政策违规。
- 官方要求原创、有用的内容，查阅的官方资格与内容政策未规定统一的 800、900 或 1,500 词门槛。本次按你的编辑目标扩写，仍须检查内容准确性。[资格要求](https://support.google.com/adsense/answer/9724?hl=en)、[低价值页面政策](https://support.google.com/publisherpolicies/answer/11112688?hl=en)。
- 本地已有 `support.html`、公开邮箱、About 免责声明；问题主要是缺明确 Contact 页及一致入口。广告脚本出现不代表账号已获批，也不证明当时实际展示广告。
- `i18n/languages.json` 是 32 个语言选项，含英文；31 个本地化首页中，23 个已设 noindex，8 个有本地化 SEO 文案。不能把报告的“35 个入口全部重复”当成当前仓库事实。实际翻译不因共用计算器模板就自动成为门页。[多语言说明](https://developers.google.com/search/docs/specialty/international/localized-versions)。
- 语言选项不证明实际访客地域。CMP 应按访问地区、广告方式与实际收集行为验证，范围包括 EEA、英国、瑞士。Consent Mode 不等于认证 CMP；非个性化广告也不当然免于同意要求。[认证 CMP 要求](https://support.google.com/adsense/answer/13554116?hl=en)。
- `ads.txt` 放在根域供抓取，不需要给每个 `/de/`、`/tw/` 目录复制一份。若有独立变现子域，再按官方子域配置核查。[ads.txt 指南](https://support.google.com/adsense/answer/12171612?hl=en)。
- 游戏工具站不因为“有交互功能”就一律禁止广告；空白、低价值、私密通讯或容易误点的画面才需要特别区分。版权声明也不能替代素材许可。

### 已完成的广告隔离

- Builds、Save Editor、Support、About、Privacy、Terms 移除 AdSense 加载脚本；已有账号 meta 保留用于验证。新 Contact 和排错指南不加载广告；Plasma 原来就没有该脚本。

- `tools/build-i18n.mjs` 在生成 noindex 页面时移除广告脚本，并在写入后运行 `tools/sync-trust-footer.mjs`，避免下次生成恢复不合适的广告。
- 这不代表全站停投。首页及部分其他内容页仍保留广告脚本；其 CMP、实际广告密度和地区配置仍需确认。noindex 本身既不禁止广告，也不修复广告政策问题，必须把广告加载与搜索收录分开管理。
- 不要仅因词数达标就重新接入广告。先完成下列 CMP 与位置验收，再逐页决定恢复。

### CMP 后台操作——仍未完成

1. 在现有 AdSense 账号的「隐私权和消息」中选择 European regulations，创建或编辑本站消息。
2. 选择 `balatrocalc.com`，填入正式隐私页 `https://balatrocalc.com/privacy-policy/`，审核实际使用的供应商与用途，按现有语言提供消息。
3. 配置同意、拒绝、管理选项，不使用预勾选和误导按钮文案；预览各语言，再发布消息。采用 Google 自带认证方案时，不需要自行制作普通 Cookie 横幅。[创建消息步骤](https://support.google.com/adsense/answer/10960768?hl=en)。
4. 若还使用需要同意信号的 Google 标签，检查 Consent Mode 设置及信号传递；不能只设置一个本地 `consent=true` 标志。[Consent Mode 设置](https://support.google.com/adsense/answer/16053245?hl=en)。
5. 在 EEA、英国、瑞士的真实测试环境，以新访客状态分别测试“未选择、拒绝、同意、撤回”。比较 Cookie/Storage、广告请求与 CMP 调试状态；拒绝后不得照常进行未经同意的个性化处理。有限广告是否允许及其存储行为按后台实际配置评估，不能只看有没有广告。
6. 确认页底有可工作的撤回入口。Google 对符合条件且展示消息的站点自动加入该入口；如果没有，按官方撤回 API 配置并验证，不放一个无法调用 CMP 的假按钮。[撤回入口](https://support.google.com/adsense/answer/10959060?hl=en)。
7. 对已暂时移除广告脚本的页面，不要为了让横幅出现而给隐私页恢复广告。先在实际投放页完成测试；主页若查明未配置 CMP，先暂停受影响投放，再恢复经过验证的方案。
